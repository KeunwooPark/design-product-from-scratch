# Chapter 6: High-fi Prototyping

High-fidelity prototyping means building a prototype that closely resembles the real final product. If you tested the structure and details of the interface with a mid-fi prototype, with a high-fi prototype you test whether the design still holds up when real content goes in and it runs on a real device at real speed. That's why high-fi prototypes are often built in code rather than in a prototyping tool such as Figma. Here too, the goal is usability testing, not building the final product itself, so you don't need to build the whole system perfectly. But it should behave as closely as possible to how users would actually use the product. For example, if the real product will inevitably have network latency for technical reasons, the high-fi prototype shouldn't run too fast either. Apart from the level of the prototype, every part of the process is the same as in the earlier prototyping stages.
